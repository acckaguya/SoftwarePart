## 证据等级

本资料包采用以下顺序选择论据。这里的“顶级”是为本报告设定的操作性标准，不等同于对全部学科会议作统一排名。

1. **A 级：正式发表于本领域旗舰会议或高影响力期刊。** 机器学习与视觉方向优先 ICLR、ICML、NeurIPS、CVPR；系统与体系结构方向优先 OSDI、SOSP、NSDI、ASPLOS、ISCA、FAST、USENIX ATC、EuroSys；HPC 方向优先 SC、HPDC、IPDPS；同时纳入 Science、Nature Machine Intelligence、JMLR、IEEE TPDS 等与主题直接相关的期刊论文。
2. **B 级：正式发表于高相关专业会议、期刊或旗舰会议的 Operational Systems Track。** 当其研究对象与小节高度一致时，可作为主引；引用时注明具体轨道。
3. **C 级：标准组织、框架或硬件厂商的官方文档与技术规范。** 用于说明格式、接口和生产实现，不用来替代论文中的有效性证据。
4. **D 级：有影响力的预印本或社区技术资料。** 仅在没有等价正式论文或其包含独有机制时保留，并明确标为“预印本/工程补充”。

主引的选择同时考虑**发表层级、与标题的直接匹配度、机制首创性、实验规模和证据可复用性**。因此，一篇更高层级但只间接相关的论文，不会自动取代一篇直接研究该问题的正式系统论文。

## 使用原则

- 正文先用主引建立机制，再从补充论文中选 1—2 篇作比较；不建议把表中所有论文逐篇罗列。
- 引用性能数据时同时写明模型、硬件、精度、请求长度、并发度和基线。不同论文的加速倍数不能脱离实验条件直接比较。
- 2026 年论文已按正式 proceedings 页面核验；形成最终参考文献表时仍应以学校要求的引文格式导出作者、页码和 DOI。
- 原资料库中的 PDF 保持原位，新版文件通过链接复用；本轮新增的 29 篇一级优先论文另存于 `新增PDF`，不重复复制旧库文件。
